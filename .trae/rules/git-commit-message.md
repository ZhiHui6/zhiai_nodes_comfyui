## Git Commit Message Rules

1. **ENGLISH ONLY** — The generated commit message MUST be entirely in English. No Chinese or any other language is allowed.
2. **Format** — Single concise line listing the main changes, prefixed with a conventional commit type: `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`, `style:`, `perf:`, `test:`, or `build:`.
3. **Scope** — Only enumerate the primary changes. Do NOT include detailed explanations, body paragraphs, or footers.
4. **Example** — `feat: add image preprocessing node, fix batch size validation`
